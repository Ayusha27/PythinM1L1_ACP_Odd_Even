# M1L1 ACP – Odd Even Flowchart

## Objective
Create a flowchart to check whether a given number is EVEN or ODD.

## Problem Statement
Write an algorithm and represent it using a flowchart to determine whether a number entered by the user is even or odd.

## Algorithm

1. Start.
2. Input a number.
3. Check whether the number is divisible by 2.
4. If the remainder is 0, display "EVEN".
5. Otherwise, display "ODD".
6. Stop.

## Flowchart Logic

- **Start:** Begin the program.
- **Input:** Enter a number.
- **Decision:** Check whether `num % 2 == 0`.
- **YES:** Display "EVEN".
- **NO:** Display "ODD".
- **Stop:** End the program.

## Python Concept Used

The modulo operator (`%`) returns the remainder after division.

Example:
- `10 % 2 = 0` → EVEN
- `7 % 2 = 1` → ODD
